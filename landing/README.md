# SchnapShot website

The landing page for [schnapshot.com](https://schnapshot.com), built with React and Vinext.

## Run locally

Requires Node.js 22.13 or later.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm start
```

The production site is hosted using Sites. Its project-specific `.openai/hosting.json` stays in the private hosting checkout and is not required for a local build.

The approved 1080p demo lives in `public/SchnapShot-interactive-1080p.mp4`. Promo production files are maintained separately from the public source.
